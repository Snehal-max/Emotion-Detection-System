# Emotion Detection System

A real-time emotion detection system using CNN and OpenCV.

## Features
- Detects 7 emotions: Angry, Disgust, Fear, Happy, Neutral, Sad, Surprise
- Real-time webcam detection
- Trained on FER2013 dataset
- 58% accuracy

## How to Run
python app.py

## Libraries Used
- TensorFlow
- OpenCV
- NumPy
